# 🪪 Validador de Formato de CPF

Script introdutório em Python que verifica se a entrada fornecida pelo usuário corresponde a um CPF composto por 11 dígitos numéricos.

## 📌 Conceitos Praticados
- Biblioteca nativa `re` (`re.search`).
- Expressão regular para quantidade fixa de dígitos (`^\d{11}$`).
- Entrada e validação de strings.

## 🚀 Como Executar

```bash
python validador_cpf.py
```
